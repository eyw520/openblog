This front page is a Markdown file — `content/pages/home.md`. Its title, the line beneath it, and this paragraph all come from there, so the first thing a reader sees can be changed without touching any code.

The list below is drawn from your most recent writing. How many appear, and which sections they come from, is set by `home` in `site.config.ts`. Set `latest: 0` to remove the list and leave the front page as an introduction on its own.
